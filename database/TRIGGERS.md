# Triggers

Los triggers ejecutan una acción dentro de PostgreSQL al producirse un evento de modificación. Se utilizarán únicamente cuando una regla de integridad o auditoría deba aplicarse en la base de datos y una restricción convencional no sea suficiente.

Actualmente no existen triggers requeridos por esta solución. No hay SQL que ejecutar y no se incorporan triggers artificiales para esta prueba. Revisar este archivo después de VISTAS.md.

Las futuras definiciones justificadas se documentarán aquí con comentarios sobre qué hacen, cómo y por qué. Se instalarán manualmente mediante pgAdmin Query Tool sobre tickets_db; la API no ejecutará su instalación.
