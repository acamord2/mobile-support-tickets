# Vistas

Las vistas presentan consultas reutilizables como relaciones SQL, por ejemplo cuando se necesite combinar tickets con sucursales sin duplicar consultas. No almacenan datos demo ni sustituyen las tablas físicas.

Actualmente no existe ninguna View requerida por esta solución. No hay SQL que ejecutar en esta etapa. Revisar este archivo después de DATABASE.md y FUNCIONES_SP.md; puede omitirse su ejecución mientras esté vacío de objetos.

Cuando una consulta combinada real lo justifique, su definición y comentarios de intención, funcionamiento y razón se agregarán únicamente aquí. La instalación será manual mediante pgAdmin Query Tool sobre tickets_db; la API no instalará vistas.
